1.
Estudante A: Interface e Experiência do Usuário (Front-end)


O foco desta pessoa é tudo que o usuário vê e interage.

Telhas e Design:

Projetar e construir a tela de login.

Projetar e construir a tela inicial com a lista de quizzes disponíveis.

Projetar e construir a tela de execução do quiz.

Projetar e construir a tela de histórico/estatísticas.

Garantir que a interface seja agradável e responsiva, seguindo as boas práticas do Material Design.

Recursos Visuais:

Implementar o dashboard.

Implementar o ranking de usuários.

2.
Estudante B: Integração com Firebase e Autenticação (Back-end/Nuvem)


O foco desta pessoa é a comunicação com o banco de dados na nuvem e o gerenciamento de usuários.

Autenticação de Usuários:

Configurar e implementar a autenticação de usuários com o Firebase Authentication (e-mail/senha, Google ou outro provedor).

Garantir que o perfil do usuário seja salvo no Firebase.

Dados do Quiz:

Estruturar e armazenar as questões do quiz no Firebase Realtime Database ou Cloud Firestore.

Implementar a lógica para salvar o desempenho de cada sessão do quiz na nuvem, junto ao perfil do usuário.

Sincronização:

Garantir que o aplicativo seja capaz de sincronizar e atualizar o banco de dados local sempre que houver novas perguntas no Firebase.

3.
Estudante C: Gerenciamento de Dados Locais e Lógica do Quiz (Lógica e Persistência)


O foco desta pessoa é a lógica do jogo e o armazenamento de dados no próprio celular do usuário.

Armazenamento Local:

Implementar o armazenamento local para o perfil do usuário, usando Room, SharedPreferences, ou similar.

Criar o banco de dados local para armazenar as questões do quiz baixadas do Firebase.

Salvar o desempenho de cada sessão do quiz localmente.

Lógica do Quiz:

Implementar a lógica para que o quiz seja dinâmico, exibindo as questões do banco de dados local.

Implementar a lógica para exibir o desempenho do usuário (pontuação, percentual de acertos, etc.) ao final de cada quiz.

Histórico:

Desenvolver a funcionalidade para que o usuário possa acessar o histórico de quizzes respondidos e visualizar suas estatísticas.
